Threads 콘텐츠 도우미 (Threads Content Helper)
최종 수정일: 2026년 8월 14일

본 방침은 운영자 개인이 자신의 Threads 계정에 올릴 게시물을 준비하기 위해 사용하는 비공개 도구에 적용됩니다. 이 도구는 일반에 배포되지 않으며, 운영자 본인 외의 사용자를 받지 않습니다.

1. 수집하는 정보

  • 운영자 본인의 Threads 계정 정보 — 계정 ID, 사용자 이름
  • 운영자 본인이 게시한 글과 그 성과 — 본문, 조회수, 좋아요, 댓글 수, 재게시 수
  • 공개 게시물의 문체 통계 — Threads 공식 검색 API로 조회한 공개 게시물에서 문장 길이, 문장 부호 사용 빈도, 어미 형태, 이모지 개수 등 통계값만 추출합니다.

2. 저장하지 않는 정보

  • 타인의 게시물 원문을 저장하지 않습니다. 통계값을 계산한 뒤 즉시 폐기합니다.
  • 타인의 계정 이름, 프로필, 식별자를 저장하지 않습니다.
  • 특정 계정을 지목해 추적하지 않습니다. 검색은 주제 키워드로만 수행합니다.

3. 사용 목적

운영자 본인이 자신의 계정에 올릴 글의 문체를 다듬는 데에만 사용합니다. 수집한 통계는 "한국어 Threads에서 잘 읽히는 문장의 평균적인 형태"를 파악하는 용도이며, 특정 게시물이나 계정을 모방하는 데 쓰지 않습니다.

4. 보관과 파기

  • 모든 데이터는 운영자의 개인 PC 안 로컬 데이터베이스에만 저장됩니다.
  • 외부 서버로 전송하지 않습니다.
  • 타인 게시물의 원문은 메모리에서만 처리되고 디스크에 기록되지 않습니다.
  • 운영자가 프로그램을 삭제하면 모든 데이터가 함께 삭제됩니다.

5. 제3자 제공

수집한 어떤 데이터도 제3자에게 제공하거나 판매하지 않습니다. 광고, 프로파일링, 마케팅 목적으로 사용하지 않습니다.

6. 외부 서비스

  • Meta Threads API — 게시물 발행 및 성과 조회
  • OpenAI API — 게시물 문구 및 이미지 생성. 전송되는 내용은 운영자가 작성할 게시물의 소재이며, 타인의 개인정보를 포함하지 않습니다.
  • GitHub — 게시물에 첨부할 이미지 파일 보관. Threads API가 공개 URL을 요구하기 때문입니다.

7. 이용자의 권리

본 도구는 운영자 본인만 사용하므로 별도의 이용자가 없습니다. 타인의 공개 게시물에서 추출한 통계값에는 개인을 식별할 수 있는 정보가 포함되지 않습니다. 자신의 게시물이 통계 산출에서 제외되기를 원하시면 아래로 연락 주시면 즉시 반영하겠습니다.
